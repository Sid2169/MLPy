# MLPy — Python for Applied AI and Backend Engineering

A self-study course for experienced TypeScript/Node.js developers who want practical Python fluency for building AI services, data pipelines, ML experiments, and production backend integrations.

Each chapter is a standalone lesson generated according to [Chapter-generation.md](Chapter-generation.md): concise teaching material focused on Python-specific semantics and idioms (with selective TypeScript comparisons), followed by an extensive, progressively ordered exercise set. Solutions are intentionally withheld — predict behavior, run the code, and reconcile.

## Working through the chapters

1. Read the lesson section, typing examples into a REPL or scratch file.
2. Attempt each exercise before running code; groups are ordered from recognition to implementation.
3. Verify predictions by running the snippets, then rewrite the tricky ones from memory.
4. Use the "Before moving on" checklist at the end of each chapter to decide whether to continue or repeat a group.
